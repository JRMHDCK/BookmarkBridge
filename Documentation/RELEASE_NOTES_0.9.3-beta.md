# BookmarkBridge 0.9.3 Beta

Merci d'essayer BookmarkBridge !

Cette bêta améliore la compatibilité avec les profils Chrome et facilite le
signalement d'un dysfonctionnement sans transmettre le contenu des favoris.

## Nouveautés

• Bouton « Signaler cette erreur » disponible directement après un échec.
• Bouton permanent « Signaler un bug » dans l'aide de l'application.
• Rapport de diagnostic local avec identifiant de suivi, contexte technique et
journal récent limité aux événements utiles.
• E-mail prérempli dans l'application de messagerie par défaut du Mac, avec le
rapport joint lorsque macOS le permet.

## Corrections

• Sélection fiable du fichier de favoris adapté aux profils Chrome utilisant
`Bookmarks` ou `AccountBookmarks`.
• Meilleure classification des erreurs de lecture, d'autorisation, de sauvegarde,
d'écriture, de validation et de restauration.
• Aucun URL, titre de favori, nom de dossier, nom d'utilisateur ou chemin local
complet n'est ajouté automatiquement au rapport de diagnostic.

BookmarkBridge est un projet open source. Tous les retours, idées d'amélioration,
signalements de bugs et contributions sont les bienvenus.
