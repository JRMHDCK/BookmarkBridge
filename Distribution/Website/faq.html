Questions fréquentes

L’essentiel pour installer et utiliser BookmarkBridge.

Que fait BookmarkBridge ?

BookmarkBridge compare vos favoris Safari et Google Chrome et permet de les synchroniser dans les deux sens après prévisualisation.

BookmarkBridge est-il gratuit ?

Oui. Le téléchargement est gratuit pendant la phase bêta.

Quelle version de macOS est requise ?

macOS 26.5 ou une version ultérieure est nécessaire.

Pourquoi macOS refuse-t-il d’ouvrir l’application ?

Gatekeeper peut demander une confirmation pour une application téléchargée hors du Mac App Store. Dans Applications, faites un clic droit sur BookmarkBridge, choisissez « Ouvrir », puis confirmez.

Mes favoris quittent-ils mon Mac ?

Non. Le traitement est local et aucun compte cloud BookmarkBridge n’est requis.

Dois-je fermer Safari et Chrome ?

Suivez les indications affichées par l’application. Elle peut demander de fermer les navigateurs avant une opération afin d’éviter une modification concurrente.

Puis-je vérifier le fichier téléchargé ?

Oui. Comparez sa somme SHA-256 avec le fichier SHA256.txt fourni sur ce site.

Où trouver le guide complet ?

Le manuel utilisateur PDF accompagne le téléchargement.
