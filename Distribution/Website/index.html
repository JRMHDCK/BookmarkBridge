Questions fréquentes

L’essentiel, sans jargon.

Mes favoris sont-ils envoyés sur Internet ?

Non. BookmarkBridge fonctionne localement sur votre Mac, sans cloud ni serveur pour traiter vos favoris.

Mes dossiers et leur ordre sont-ils conservés ?

Safari → Chrome préserve la structure par écriture transactionnelle. Chrome → Safari conserve la structure des nouveaux favoris importés, mais l’import additif ne peut pas appliquer les suppressions, déplacements, renommages ou changements d’URL.

Faut-il installer une extension dans Safari ou Chrome ?

Non. BookmarkBridge est une application macOS autonome : aucune extension ni aucun plugin de navigateur ne sont nécessaires.

Comment BookmarkBridge accède-t-il aux favoris ?

Uniquement après votre autorisation explicite, via les permissions officielles proposées par macOS.

Quand l’application sera-t-elle disponible ?

La bêta macOS est disponible gratuitement. Téléchargez le DMG depuis la page de téléchargement, puis glissez BookmarkBridge dans Applications.
