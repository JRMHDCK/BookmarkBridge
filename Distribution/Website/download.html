Installation

  1. 1
    Téléchargez et ouvrez le fichier DMG.
  2. 2
    Glissez BookmarkBridge dans le raccourci Applications.
  3. 3
    Ouvrez le dossier Applications puis lancez BookmarkBridge.
  4. 4
    Accordez uniquement les accès Safari et Chrome nécessaires.

Si macOS bloque la première ouverture

Dans le dossier Applications, faites un clic droit sur BookmarkBridge, choisissez Ouvrir, puis confirmez avec Ouvrir. Cette opération n’est normalement nécessaire qu’une fois.
